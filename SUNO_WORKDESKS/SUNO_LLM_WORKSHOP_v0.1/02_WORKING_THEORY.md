# 02 — Working Theory

Labels: **OBS** observation; **ROBS** repeated observation; **HYP** hypothesis; **PR** provisional rule; **VB** version-bound; **OPEN** unresolved.

## Operational model

- **HYP:** A Suno prompt is a compressed conceptual song-world, not executable source code.
- **HYP:** Suno negotiates a musical realization among objects, relations, priors, lyric geometry and settings.
- **PR(v5.5-current corpus):** plain Lyrics text is strongly vocal-eligible.
- **HYP:** square-bracketed Lyrics text is more likely to act as structural/sonic pressure, metadata, performance direction, or omission than as ordinary lyric.
- **HYP:** Styles carries global physics: source ontology, engine, priorities, persistent attractors and permissions.
- **OBS:** real code can become useful vocal material; compact control phrases can be promoted to refrains.
- **OBS:** repeated `if missing`, `for variable...`, and `if key, symbol` became sung material in the current code experiment.
- **HYP:** exact phrase anchors plus nearby musical consequences can create local semantic binding.
- **OPEN:** whether trigger effects are truly localized, retriggered, globally infused, or merely correlated with lyric position.

## Semantic distance

- **HYP:** local definition is generally more dependable than distant symbol-table lookup.
- Global declarations should define only genuinely global properties.
- Regional/local events should name enough of the affected musical object and consequence at point of use.

## Permission and capability framing

- **HYP:** presupposing an impossible object as already instantiated may make an inventive solution more available than merely requesting novelty.
- Procedural framing can recast overload as a legitimate search problem rather than an incoherent genre stack.
- Current candidate strategy: reverse common-association weighting while protecting compelling hook formation.

## Construction / rupture duality

- Constructed systems supply identity, causality and a meaningful object to violate.
- Rupture supplies overload, contradiction, false boundaries, impossible requests and self-surprise.
- Neither is universally prior. A malformed object can precede and generate its own retrospective structure.

## Quality model

- **Control value:** desired relationship appears.
- **Surprise value:** output contributes something valuable not explicitly designed.
- **Conventionality cost:** Suno resolves pressure through familiar genre, vocal, dramatic or production defaults.
- **Sterilization cost:** revision removes edge-friction, instability or strange local behavior that gave the result identity.
