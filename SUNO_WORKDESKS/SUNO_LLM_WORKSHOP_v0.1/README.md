# SUNO LLM WORKSHOP v0.1

Purpose: build, break, test, hear, and revise conceptual song systems for Suno without mistaking prompt notation for a deterministic programming language.

## Operating loop

compile → construct → rupture → generate → listen → harvest → recombine → revise

## Success classes

- **CONTROL:** an intended relationship appears.
- **SURPRISE:** a valuable result appears outside the explicit design.
- **HYBRID:** a protected invariant survives model invention.

## Source discipline

1. direct prompt/result artifact;
2. Nathan's listening observation;
3. repeated observation;
4. model inference;
5. prior assistant assertion;
6. external claim requiring verification.
