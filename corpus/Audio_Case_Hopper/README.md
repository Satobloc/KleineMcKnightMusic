# Audio Case Hopper

Intake for source-linked audio examples and prompt-to-output cases.

Prioritize cases with both original prompt(s) and output audio. Record model/version, creation date, generation settings, references/personas, task type, title, audio URL or platform permalink, duration, and rights/access constraints.

Do not download or mirror audio automatically. Keep source URLs and metadata; obtain separate permission before republishing or redistributing audio. Human listening notes and machine measurements must be separately attributed.
