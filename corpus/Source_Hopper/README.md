# Source Hopper

Shared provenance-first intake for web sources, documentation, papers, repositories, datasets, APIs, creator experiments and reference material.

Nothing here is endorsed, verified, licensed, or approved for reuse merely because it has been collected.

## Required distinctions
- Source statement
- Directly observed artifact
- User/creator-reported result
- Author interpretation
- Our hypothesis
- Independently replicated result

Preserve canonical URL, retrieval date, publication date when known, source type, author, relevant excerpt, access method, license/terms notes, and confidence. Store compact metadata and short justified excerpts; link to the original rather than copying entire copyrighted works.

Each intake record should be immutable after capture. Corrections and later assessments belong in separate review records.
