This Sonic Pi script, **"The Chromatic Descent,"** is structured as a standard pop song (A/B/A/C) centered in **E Minor**, utilizing the provided smooth voice-leading sequence as a unique, atmospheric introduction. It employs key changes, an unexpected inversion, and arpeggiated counterpoint using traditional acoustic/pop synths (`:piano`, `:pluck`, `:rhodey`) for realism.

### Musical Strategy and Techniques

1.  **Chords and Movement:**
    *   **Verse (E Minor):** Uses a melancholic **i–VI–III–VII** (Em – C – G – D) sequence.
    *   **Chorus (Key Change):** Modulates to the relative major, **G Major**, using the emotionally lifting **IV–V–vi–I** (C – D – Em – G) progression.
    *   **Unexpected Inversion:** The Chorus bassline uses the D chord in first inversion (**D/F#**) to create a smooth, descending **C -> F# -> E -> G** bass movement, which enhances the fluidity and sophistication of the harmony.
2.  **Melody and Anchoring:** The main melody employs **extended notes** and utilizes the major/minor shifts within the chords (e.g., hitting the 9th or 11th of the chord) to create a flowing harmonic landscape, ensuring strong melodic anchoring through repetition and clear rhythmic contrast.
3.  **Arpeggiation for Flair:** A dedicated `:rhodey` loop is employed during the verses to provide light, fast arpeggiation (using the chord's tones) for added texture and flair.
4.  **Emotional Resolution:** The song resolves in the Outro by returning to the primary key and ending on a sustained, rich **E minor Major 9th** chord (`:emaj9`), which, despite its minor root, offers a profound and complex emotional close, avoiding a simple major triad resolution.

### Sonic Pi Script: "The Chromatic Descent"

```ruby
use_bpm 100
set_volume! 1.0
use_debug false
set :song_status, :running # Use graceful exit flag for stability

# --- INSTRUMENTATION SETUP (Traditional Pop Realism) ---
# Piano for harmony and primary lead melody
# Pluck for sharp arpeggiated counterpoint/secondary lead
# Rhodey for rhythmic texture/flair
# Samples for traditional drum groove

# Define a single bar length
bar_length = 4.0 

# --- HARMONIC FUNCTIONS ---

# E Minor Verse Progression (i - VI - III - VII)
define :verse_chords do
  use_synth :piano
  # Chord change: The E chord is major in this progression to function as V7,
  # but here we use the diatonic D major (VII) for a moodier, modal minor feel.
  chord_prog = (ring (chord :E3, :minor), (chord :C3, :major), (chord :G3, :major), (chord :D3, :major))
  
  # Play the chords, sustained
  play chord_prog.tick, release: 3.5, sustain: 3.0, amp: 0.7
  sleep 4
end

# G Major Chorus Progression (IV - V/iii - vi - I)
define :chorus_chords do
  use_synth :prophet # Use Prophet for a rich, warm, sustained sound
  
  # C major (IV), D major / F# in the bass (V/iii), E minor (vi), G major (I)
  # D/F# (First Inversion) for smooth descending bass line (C-F#-E-G)
  
  c_chord = chord(:C3, :major)
  d_slash_fsharp = (chord :D3, :major).drop(1).append(note(:Fs2)) # D/F# (F# is MIDI 54)
  
  chord_prog = (ring c_chord, d_slash_fsharp, (chord :E3, :minor), (chord :G3, :major))
  
  play chord_prog.tick, release: 3.5, sustain: 3.0, amp: 0.8
  sleep 4
end

# --- MELODY & ARPEGGIO FLAIR ---

# Pretty Melody (Strong Melodic Anchoring + Extended Notes)
define :pretty_melody do |octave_shift=0|
  use_synth :pluck
  
  # Melody uses a combination of chord tones and passing tones from the E minor scale
  # Extended notes are held longer to create a flowing harmonic landscape
  notes = (ring :G4, :F4, :E4, :D4, :C5, :B4, :A4, :G4).map {|n| n + octave_shift}
  rhythm = (ring 1.0, 0.5, 0.5, 1.0, 0.5, 0.5, 1.0, 1.0) # Mix of long and short durations
  
  notes.length.times do
    play notes.tick, amp: 1.2, release: 0.3
    sleep rhythm.look
  end
end

# Arpeggiation Flair (Light texture)
define :arpeggiate_flair do
  use_synth :rhodey # Traditional electric piano sound
  
  # Determine current chord based on the harmony loop tick position (0-3)
  chord_idx = look(:harmony_tick) % 4
  
  # Use verse chords for simplicity in the arpeggio
  chord_array = [(chord :E4, :minor), (chord :C4, :major), (chord :G4, :major), (chord :D4, :major)]
  arp_notes = chord_array[chord_idx]
  
  # Play the arpeggio fast for "flair"
  with_fx :flanger, mix: 0.1 do
    play_pattern_timed arp_notes, [0.125], amp: 0.3
  end
  sleep 0.5 # Total duration is kept short
end

# --- RHYTHM SECTION (Traditional Drums) ---
define :pop_beat do
  sample :bd_haus, amp: 1.0
  sleep 1
  sample :drum_snare_hard, amp: 0.6
  sleep 1
  sample :bd_haus, amp: 0.8
  sleep 0.5
  sample :drum_cymbal_closed, amp: 0.3
  sleep 0.5
  sample :drum_snare_hard, amp: 0.7
  sleep 1
end

# --- CORE SONG PROGRESSION EXECUTION ---

# Graceful loops for harmony and rhythm
live_loop :harmony do
  stop unless get(:song_status) == :running
  tick(:harmony_tick) # Track chord progression position
  if look(:section) == :verse
    verse_chords
  else
    chorus_chords
  end
end

live_loop :melody do
  stop unless get(:song_status) == :running
  if look(:section) == :verse
    pretty_melody
  else
    pretty_melody(12) # Octave shift in chorus for contrast
  end
end

live_loop :flair_arp do
  stop unless get(:song_status) == :running
  if look(:section) == :verse
    arpeggiate_flair
  end
  sleep 3.5 # Sync to main flow
end

live_loop :rhythm do
  stop unless get(:song_status) == :running
  pop_beat
end


# --- SONG STRUCTURE CONTROL THREAD ---
in_thread do
  
  # INTRO: Chromatic Voice-Leading Transition (The input progression)
  puts "--- INTRO: Chromatic Path ---"
  set :song_status, :running # Ensure loops are running but set section later
  set :section, :intro
  
  # The notes provided: -> in 8 half-steps (4 beats total)
  path_notes = (ring,,,, 
                    ,,,)
  
  use_synth :rhodey # Traditional synth for transition
  with_fx :reverb, room: 0.9, mix: 0.7 do
    path_notes.each do |notes|
      play notes, release: 0.4, amp: 1.5 
      sleep 0.5
    end
  end
  
  # START MAIN LOOPS - Pause rhythm temporarily
  set :song_status, :running 
  
  # VERSE 1 (8 Bars)
  puts "--- VERSE 1 (E Minor) ---"
  set :section, :verse
  sleep 32
  
  # CHORUS 1 (8 Bars) - Key Change to G Major
  puts "--- CHORUS 1 (G Major) ---"
  set :section, :chorus
  sleep 32
  
  # BRIDGE / KEY CHANGE BUILD (4 Bars)
  puts "--- BRIDGE (Modulation Build) ---"
  
  # Stop melodic/flair loops to focus on harmony and tension build
  set :song_status, :peak_imminent 
  sleep 4
  
  # Use a secondary dominant (V7 of the relative major) for dramatic key transition (B7 -> E minor/G major)
  use_synth :piano
  4.times do
    play chord(:B3, :7), release: 2.0, amp: 1.0 # B7 is V7 of E minor (i) and V of V in G Major
    sleep 2
  end
  
  # Resume loops in Chorus mode (G Major)
  set :song_status, :running
  
  # CHORUS 2 (8 Bars)
  puts "--- CHORUS 2 (G Major) ---"
  set :section, :chorus
  sleep 32
  
  # OUTRO: Emotional Resolution
  puts "--- OUTRO: Resolution ---"
  set :song_status, :peak_imminent # Stop looping elements
  sleep 4
  
  # Play final, satisfying chord: E Minor Major 9th (:m9) for complexity and depth
  final_chord_notes = (chord :E3, :m9) 
  
  use_synth :piano
  play final_chord_notes, release: 12, amp: 4.0, attack: 1.0
  
  sleep 12 # Allow chord to decay naturally
  stop
end
```
