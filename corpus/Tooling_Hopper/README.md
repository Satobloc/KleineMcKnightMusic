# Tooling Hopper

Intake for scrapers, APIs, datasets, browser tools, analysis utilities, prompt builders, audio-analysis tools and community-made applications.

Record repository/package canonical URL, license, maintenance status, dependencies, authentication requirements, rate limits, platform terms, privacy implications, and whether the tool is reference-only, candidate, experimental or adopted.

Never collect credentials or bypass access controls, paywalls, robots restrictions, or platform limits.
