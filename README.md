# KleineMcKnightMusic

A modular composition and music-systems workshop.

The project brings together formal musical modeling, musical knowledge, generative systems, audio processing, execution backends, and controlled creative experiments. It is not limited to one generator or one production workflow.

## Working principles

- Calculate musical structure in our own tools where exactness matters.
- Translate formal structures into perceptual language when prompting generative systems.
- Keep source observations, hypotheses, and interpretations distinct.
- Preserve original prompts and source artifacts verbatim.
- Record tool versions, settings, dependencies, licenses, and verification status.
- Treat examples and prototypes as untrusted until tested.
- Keep private lyrics, conversations, and rights-restricted material out of this public repository.

## Architecture

The workshop has three connected planes:

1. **Music engine:** timing, rhythm, harmony, melody, prosody, arrangement, and formal composition.
2. **Musical knowledge:** genres, traditions, instruments, techniques, terminology, and perceptual descriptions.
3. **Experimental system:** prompts, model/version/settings, generated outputs, evaluation, and reproducibility.

A shared MusicBlueprint will eventually connect these planes to multiple backends, including Sonic Pi, MIDI/symbolic music, audio analysis, and generative services.
