# VOYNICH

A home for the Voynich music project and related creative work.

Use this project folder for working notes, musical ideas, arrangements, experiments, scripts, and project-specific documentation. Keep the distinction between creative play and formal analysis: neither needs to dictate the shape of the other.

Preserve source provenance and original filenames when bringing material into the repository. Follow the repository's existing corpus, rights, privacy, and publication guidelines. Private lyrics, conversations, raw uploads, and rights-restricted source material do not belong in this public repository.

The existing Voynich audio-analysis workdesk is on the `research/voynich-audio-lab` branch under `corpus/Structure_Hopper/VOYNICH_AUDIO_LAB/`; it remains separate from this project space.
